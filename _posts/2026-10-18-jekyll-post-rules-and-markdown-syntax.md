## 🟩 Jekyll에서 글 작성 규칙 

지금 내가 쓰고 있는 것처럼, 
글 맨위 --- 사이에 Jekyll에 전달하는 글의 설정을 작성해준다. <br>
어떤 글의 설정을 써야하는지는 본인의 Jekyll 테마의 공식 문제, README이런걸 참고하여 작성하도록 한다.  <br>
만약 공식문서를 읽기 귀찮다면 해당 테마의 깃허브 레포지토리로 가서 예제를 참고하면 될 것같다.  <br>

또한 이 \---- 두 줄 사이를 ***Front Matter***라고 부른다고 한다. <br>
Front Matter는 **파일 맨 처음**에 있어야 하며, '**항목: 값**' 형태의 YAML 문법을 사용한다. 콜론 뒤에는 공백을 넣어준다. 
아래는 그 예시이다. <br>

```yaml
---
layout: post
title: "JPA Entity 공부 정리"
date: 2026-10-19 10:00:00 +0900
categories: [Backend, JPA]
tags: [java, spring, entity]
---
```

<br>

## 🟩 앞으로 많이 사용할 것 같은 md 파일 문법
'#', '-' 이런 기호들 쓰는 정도는 알기에, 내가 몰랐고, 앞으로 자주 쓸 것 같은 문법 위주로 작성하겠다.  <br>

### 1. 체크 리스트
```md
- [ ] 글 작성하기
- [ ] 코드 예제 확인하기
- [x] 레포지토리 clone하기
```
[ ]는 미완료, [x]는 완료를 뜻 한다. 
실제로 보이는 화면은 아래처럼 보일 것이다. 

- [ ] 글 작성하기
- [ ] 코드 예제 확인하기
- [x] 레포지토리 clone하기
<br>

### 2. 코드

**짧은 코드나 용어의 경우**

짧은 코드나 용어를 문장 안에서 표시하려면 **백틱 하나**로 감싸면 된다.
ex) `findById()`는 ID로 Entity를 조회하는 메서드이다.

**여러 줄 코드의 경우**

3개 이상의 백틱으로 감싸면 된다. 그리고 상단 백틱 옆에 확장자를 적어준다. <br> (여기서는 java를 적었다.)
````md
```java
public class Member {
    private Long id;
    private String name;
}
```
````
<br>
그러면 화면에는 다음과 같이 보일 것이다.
```java
public class Member {
    private Long id;
    private String name;
}
```
혹시나 다음과 같이 폴더 구조같이 이렇게 텍스트로 표현하고자 한다면 <br>
다음과 아래과 같이 확장자에 text를 써주면 될 것이다. <br>
정렬이 그대로 유지된다. 

```text
src/
├── controller/
├── service/
└── repository/
```

````md
```text
src/
├── controller/
├── service/
└── repository/
```
````

### 3. 인용문
다음과 같이 '>'를 사용하면된다. 

````md
> Entity는 DB 테이블에 매핑되는 Java 클래스이다.
````

화면에는 다음과 같이 보인다. 

> Entity는 DB 테이블에 매핑되는 Java 클래스이다.

### 4. 링크
1. 다른 웹 사이트로 이동
      ```md
      [GitHub 방문하기](https://github.com)
      ```
   
   이렇게 `[화면에 보일 글자](실제 링크)` 형식으로 작성하면 된다.
   화면에는 다음과 같이 보일 것이다.
   [GitHub 방문하기](https://github.com)

2. 같은 문서안에서 제목으로 이동 (앵커)
   (이건 굳이 지금은 안쓸거 같아서 다음에 알아볼때 추가하겠다)
   


### 5. 이미지 
링크 문법에 **!추가**하면 이미지이다.
```md
![대체 텍스트](/assets/images/jpa-relation.png)
```

이런 식으로 작성하면 된다. <br>
대체 텍스트는 이미지 로딩 실패시 띄우는 그런 용도로 적는 것이고, <br>
뒤에 ()안에는 이미지가 있는 경로를 적거나, 아니면 웹에 있는 이미지를 가져온다고 한다면 url을 적으면 된다. 

### 6. 표
```md
| 구분 | Entity | DTO |
| --- | --- | --- |
| 역할 | DB 데이터와 매핑 | 데이터 전달 |
| 사용 위치 | 영속성 계층 중심 | 요청·응답 등 |
```

이런식으로 \-와 \|를 사용하여 표를 만들면 된다. <br>
두 번째 행에 있는 '---'이건 제목 행과 데이터 행을 구분하는 필수 줄이다. <br>
꼭 넣자. <br>
    
저렇게 작성하면 화면에는 다음과 같이 보이게 된다.

| 구분 | Entity | DTO |
| --- | --- | --- |
| 역할 | DB 데이터와 매핑 | 데이터 전달 |
| 사용 위치 | 영속성 계층 중심 | 요청·응답 등 |

   
### 7. 가로 구분선
\--- 를 사용하면 된다. <br>
또한 Jekyll 파일 맨 위의 ---는 앞에서 배운 Front Matter 구분자로 쓰이므로, <br>
\--- 위아래에 빈칸을 넣는 등 주의하도록 하자.  <br><br>

### 8. 특수 문자 그대로 표시 
\\를 사용하면 된다. <br>
예를 들자면, \\#, \\* 이런식으로 말이다.  <br>

### 9. 주석
html이랑 똑같이 
```md
<!-- -->
``` 
이렇게 쓰면 된다. <br>
소스 코드에서는 당연하게도 보이지만, 화면에서는 안보인다.
