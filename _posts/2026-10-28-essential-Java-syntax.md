## 🟩 함수(메서드)에 변수나 배열 넘기기 (복사 호출, 참조호출)
함수를 호출할 때 넘기는 데이터를 인자<sup><strong>Argument</strong></sup>라고 하고, <br>
호출받은 함수에서 넘어온 인자를 받는 변수를 파타미터<sup><strong>Parameter</strong></sup>라고 한다. <br>
이정도는 알 것이다. 

함수 sample(x)를 호출한다고 했을 떄, 복사 호출은 **변수 x의 값**을 넘기고, <br>
참조 호출은 변수 x의 레퍼런스(식변자, 포인터 또는 주소)를 넘긴다. 


이때, **자바는 기본적으로 복사호출**이므로, 파라미터에 변수 x의 값을 복사해서 사용한다. <br>
따라서 원래 호출했던 곳에 있던 변수 x의 값은 변하지 않을 것이다. 

아래와 같이 파라미터의 값을 2배하는 함수를 살펴보자. 
````java
void twofold(int a) {
    a = 2 * a;
}
````

````java
int x = 5;
twofold(x);
````

이 코드를 살펴보았을때, 함수 twofold에 있는 파라미터인 a의 값은 2배되지만, x의 값은 변하지 않는다. <br>
x의 값이 ***복사***되어 함수 twofold에 전달되었기 때문이다.


하지만, 배열의 경우에는 말이 달라진다. 
자바의 배열 이름은 그 배열의 레퍼런스 값인 id, 즉 배열을 식별할 수 있는 식별자를 갖고 있다. <br>
즉, 함수의 인자로 배열 이름이 적히면 함수가 수행될 때 . 배열의 id값이 복사된다. <br>
id 값은 실제 배열이 있는 곳에 접근하게 해줄 수 있으므로, '배열 자체를 복사'하지 않아도 원래 배열에 접근할 할 수 있다.
본인이 C 언어의 포인터 개념을 학습해본적이 있다면 더욱 이해하기 쉬울 것이다. <br>

즉, 배열의 경우에는 결과적으로 **참조호출**을 하는 셈이다. 
물론 주소 또한 **복사**되어 함수에 전달되지만, 그 전달하는 데이터가 어떤 변수의 **값**이 아닌 **레퍼런스 값(주소)**이다. 
그냥 주소는 뭐 어떻게 전달되나 궁금할 수도 있어서 말해보았다. 

아래 배열의 요소의 값을 바꾸는 함수 코드 예시를 보자.
````java 
sampleAccess(int b[], int n) {
    b[n] = 8;
}
````

````java 
int[] a = new int[10];
a[5] = 7;
int k = 5;
sampleAccess(a, k);
````

sampleAccess 함수에서는 원래의 배열 공간에 접근하여 값을 수정하는 것이다.
이 부분때문에, 우리는 다음과 같이, 
`a = sampleAccess(a, k);`뭐 이런식으로 값이 수정된 배열을 함수에서 다시 반환하는 식으로 코드를 짤 필요가 없는 것이다. 
또한 여기서 배열 공간이라는 말을 써서 헷갈릴 수 있는데, 
자바에서 배열명은 배열이 할당된 메모리 공간을 가리키는 id라는 사실을 다시 한번 더 상기시킨다면 이해하기 쉬울 것이다.
